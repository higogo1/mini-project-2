## 작업 추가 규칙

- 번호는 다시 쓰지 않는다. 지운 작업은 상태를 `보류`로 두고 비고 대신 progress.md에 이유를 적는다.
- 완료 조건은 다른 사람이 확인할 수 있는 문장으로 쓴다. ("잘 됨" 금지)
- 작업이 하루 넘게 걸릴 것 같으면 둘로 나눈다.
