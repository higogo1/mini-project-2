# 요구사항

무엇이 되어야 하는지 적는다. 어떻게 만들지는 design.md에 적는다.
상태: 초안. 장르는 타워디펜스로 정했다. 5절 요구사항은 아직 초안이며 T-03에서 확정한다.

마지막 수정: 2026-10-21

## 1. 한 줄 소개

정해진 것: 장르는 타워디펜스.
초안 (확정 전): "정해진 길을 따라 몰려오는 적을, 길가에 타워를 세워 막아내는 2D 타워디펜스"
핵심 재미 한 줄은 아직 정하지 않았다. (T-01 남은 부분)

## 2. 목표

- 브라우저에서 설치 없이 바로 플레이된다.
- 처음 보는 사람이 설명 없이 30초 안에 조작법을 알 수 있다.
- 한 판이 짧아서 다시 하기 쉽다. (목표 시간은 장르 결정 후 정한다)

## 3. 하지 않을 것 (이번 범위 밖)

- 로그인, 서버, 온라인 순위표
- 결제, 광고
- 모바일 앱 출시 (모바일 브라우저 지원은 7절에서 따로 정한다)

## 4. 실패로 보는 경우

기능은 돌아가도 아래면 실패로 본다.

- 첫 화면이 3초 넘게 비어 있다.
- 조작이 늦게 반응한다고 느껴진다. (프레임 저하)
- 새로고침하면 진행이 사라진다. (저장 기능을 넣기로 한 경우)

## 5. 게임 요구사항 (타워디펜스 초안)

번호를 붙여 적고, tasks.md 작업이 어느 번호를 구현하는지 연결한다.
아래 R-01~R-08은 일반적인 타워디펜스 구성을 바탕으로 한 초안이다. T-03에서 하나씩 확정하거나 고친다.

| 번호 | 요구사항 | 우선순위 | 상태 |
|---|---|---|---|
| R-01 | 적은 맵에 정해진 길을 따라 시작점에서 도착점까지 이동한다 | 필수 | 초안 |
| R-02 | 플레이어는 길이 아닌 칸에 골드를 내고 타워를 설치한다 | 필수 | 초안 |
| R-03 | 타워는 사거리 안의 적을 자동으로 공격한다 | 필수 | 초안 |
| R-04 | 적을 처치하면 골드를 얻는다 | 필수 | 초안 |
| R-05 | 시작 화면, 플레이, 게임오버 화면이 있고 다시 시작할 수 있다 | 필수 | 확정 |
| R-06 | 적은 웨이브 단위로 나오고, 웨이브가 지날수록 강해진다 | 필수 | 초안 |
| R-07 | 적이 도착점에 닿으면 생명이 줄고, 0이 되면 게임오버. 모든 웨이브를 막으면 승리 | 필수 | 초안 |
| R-08 | 타워를 업그레이드하거나 팔 수 있다 | 있으면 좋음 | 초안 |
| R-09 | 최고 기록(도달 웨이브 또는 점수)을 저장하고 다음 실행에서 복원한다 | 필수 | 초안 |

우선순위: 필수 / 있으면 좋음 / 나중에
