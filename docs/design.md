# 설계

어떤 구조로 만들지 적는다. 무엇을 만들지는 requirements.md에 있다.
상태: 초안. 기술 스택과 씬 흐름은 정했고, 타워디펜스 구조(6절)는 초안이다.

마지막 수정: 2026-10-21

## 1. 기술 선택

| 항목 | 선택 | 이유 |
|---|---|---|
| 게임 엔진 | Phaser 3 | 2D 웹게임용으로 물리, 씬, 입력, 사운드가 다 있고 자료가 가장 많다. MIT 라이선스 |
| 빌드 도구 | Vite | 설정 없이 바로 개발 서버가 뜨고 빌드가 빠르다 |
| 언어 | JavaScript (ES 모듈) | 진입 장벽을 낮추려고. 규모가 커지면 TypeScript 전환을 검토한다 |
| 저장 | 브라우저 localStorage | 서버 없이 최고 점수나 설정을 남길 수 있다 |
| 테스트 | 수동 플레이 확인 + 필요 시 Playwright 스크린샷 | 초반에는 실행 확인이 가장 빠르다 |

Phaser 버전은 T-05에서 설치한 정확한 버전을 여기에 적는다: (미기록)

## 2. 씬 흐름

```
BootScene -> MenuScene -> GameScene -> GameOverScene
                ^                          |
                +---------- 다시 시작 -------+
```

| 씬 | 하는 일 | 다음 씬 |
|---|---|---|
| BootScene | 에셋을 모두 불러오고 진행률을 보여준다 | MenuScene |
| MenuScene | 제목, 시작 버튼, 최고 점수, 소리 켜기/끄기 | GameScene |
| GameScene | 실제 플레이. 골드, 생명, 웨이브 관리 | GameOverScene |
| GameOverScene | 최종 점수, 최고 점수 갱신, 다시 시작 | MenuScene 또는 GameScene |

GameOverScene은 장르에 따라 GameScene 위에 겹쳐 띄우는 방식으로 바뀔 수 있다. 바뀌면 결정 기록에 남긴다.

## 3. 폴더와 책임

| 위치 | 책임 | 넣지 않을 것 |
|---|---|---|
| src/main.js | Phaser.Game 생성, 씬 등록 | 게임 규칙 |
| src/config.js | 화면 크기, 속도, 점수 같은 숫자 상수 | 로직 |
| src/scenes/ | 씬 하나당 파일 하나 | 여러 씬이 같이 쓰는 기능 |
| src/objects/ | 타워, 적, 투사체 클래스 | 씬 전환 |
| src/systems/ | 점수, 저장, 사운드 같은 공통 기능 | 특정 씬 전용 코드 |
| src/data/ | 레벨, 적 수치 JSON | 코드 |
| public/assets/ | 이미지, 사운드, CREDITS.md | 소스 코드 |

## 4. 화면

- 기준 해상도: 800 x 600 (장르가 정해지면 다시 본다)
- 크기 조절: Phaser Scale.FIT + CENTER_BOTH로 비율 유지

## 5. 저장 형식

localStorage 키 하나에 JSON으로 저장한다.

```
키: webgame.save.v1
값: { "version": 1, "highScore": 0, "soundOn": true }
```

형식을 바꾸면 version을 올리고, 옛 형식을 읽었을 때의 처리(초기화 또는 변환)를 이 절에 적는다.

## 6. 타워디펜스 구조 (초안, T-04에서 확정)

후보 오브젝트와 책임:

| 위치 | 이름 | 책임 |
|---|---|---|
| src/objects/ | Enemy | 길(경로점 목록)을 따라 이동, 체력, 처치 시 골드 |
| src/objects/ | Tower | 사거리 안 적 찾기, 공격 주기, 업그레이드 단계 |
| src/objects/ | Projectile | 타워에서 적까지 날아가 피해를 줌 |
| src/systems/ | WaveManager | 웨이브별 적 종류, 수, 등장 간격 (src/data/waves.json) |
| src/systems/ | Economy | 골드, 생명 관리 |
| src/systems/ | Grid / MapLoader | 설치 가능한 칸과 길 정보 (src/data/maps/) |

아직 채울 것:

- 게임 오브젝트 목록 확정과 각 클래스의 책임
- 충돌 규칙 (무엇이 무엇과 부딪히면 어떻게 되나)
- 난이도 변화 방식
- 데이터 파일 형식 (src/data/)
